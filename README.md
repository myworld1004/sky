# sky

## 🎮 뽑기마스터

브라우저에서 바로 즐기는 인형뽑기 게임이에요. `index.html` 파일을 열면 시작!

### 플레이 방법
- ◀ ▶ 버튼(PC는 ← →)으로 집게를 움직이고 **뽑기!**(스페이스)로 내려요.
- 기계 안에는 크기가 모두 다른 인형 5개가 무작위 종류·위치로 들어 있어요.
- 집게 힘은 **중간**: 가운데를 잘 맞출수록, 작은 인형일수록 잘 잡혀요. 올라가다가 또는 옮기다가 떨어질 수도 있어요!
- 인형을 **OUT** 구멍에 떨어뜨리면 **STAGE 클리어!**

### 보석 보상 (인형 크기 순)
| 크기 | 1스테이지 보석 |
|---|---|
| 1번째로 큰 인형 | 6 |
| 2번째 | 5 |
| 3번째 | 4 |
| 4번째 | 2 |
| 5번째 | 1 |

스테이지가 올라갈 때마다 모든 인형의 보석이 **+1**씩 늘어나요.

### 집게 스킨 뽑기
- 첫 뽑기는 보석 **25개**, 뽑을 때마다 필요한 보석이 **+1**씩 늘어나요.
- 스킨 20종: 레어 6종 · 레어레어 5종 · 희귀 4종 · 슈퍼레어 3종(무지개, 번개, 하트) · 시크릿 2종(은하수, 왕관)
- 확률: 레어 50% · 레어레어 28% · 희귀 15% · 슈퍼레어 5% · 시크릿 2%
- 도감에서 가진 스킨을 눌러 장착할 수 있어요. 진행 상황은 브라우저에 자동 저장돼요.

### ✨ 특별한 인형
- 가끔 반짝이는 **✨황금 인형**(보석 ×2)과 **🌈무지개 인형**(보석 ×3)이 나와요.
- 스테이지마다 황금 20%, 무지개 7% 확률로 인형 하나가 특별해져요. 상점 부스트와 함께 쓰면 곱해져요!
- 배틀에서는 황금 인형 2점, 무지개 인형 3점이에요.

### 🧸 인형 도감
- 뽑은 인형이 도감에 모이고 "3번 뽑음"처럼 기록돼요. 황금·무지개 인형을 뽑은 횟수도 따로 표시돼요.
- 인형 9종을 모두 모으면 **보석 +50** 보너스! (배틀에서 뽑은 인형도 도감에 들어가요)

### 🎁 매일 출석 보상
- 하루에 한 번 게임을 열면 보석을 받아요: 1일 💎5 · 2일 💎5 · 3일 💎10 · 4일 💎10 · 5일 💎15 · 6일 💎15 · **7일 💎50**
- 하루라도 빠지면 1일차부터 다시 시작해요. 7일을 다 채우면 다시 1일차부터 시작해요.

### 🛒 상점
- **보석 ×2** (1분) — 💎105
- **보석 ×3** (1분) — 💎110
- 부스트가 켜진 동안 인형을 뽑으면 보석을 2배/3배로 받아요. 한 번에 하나만 쓸 수 있어요.

### ⚔️ 2인 배틀 모드
- 한 화면에 기계 2대! 핑크팀 vs 블루팀이 **2분** 동안 누가 인형을 많이 뽑는지 대결해요.
- 인형을 뽑으면 그 자리에 새 인형이 채워져요. 2분이 지나면 승리 팀을 발표해요.
- 키보드: 핑크팀 A D 이동 · S 뽑기 / 블루팀 ← → 이동 · ↓ 뽑기
- 이긴 팀 보상: 💎10 + 이긴 팀 점수 1점당 💎2 (무승부는 💎5, 둘 다 0개면 보상 없음)

### 🔊 소리
- 집게가 움직일 때 기계음, 인형을 뽑으면 "Perfect!" 효과음이 나와요. 오른쪽 위 🔊 버튼으로 끌 수 있어요.

### 📱 휴대폰에 앱처럼 설치하기
1. GitHub 저장소 **Settings → Pages** 에서 *Deploy from a branch* 를 고르고, 게임이 있는 브랜치와 `/ (root)` 를 선택해 **Save**
2. 몇 분 뒤 휴대폰에서 `https://myworld1004.github.io/sky/` 접속
3. 홈 화면에 추가
   - **아이폰(사파리)**: 아래 공유 버튼(□↑) → **홈 화면에 추가**
   - **안드로이드(크롬)**: 오른쪽 위 ⋮ → **앱 설치** 또는 **홈 화면에 추가**
4. 홈 화면의 곰돌이 아이콘으로 실행! 한 번 열면 인터넷 없이도 플레이할 수 있어요.
